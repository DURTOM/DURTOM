Bidcom Precios

1Categorías de Bidcom

Pegá la dirección de cada categoría, una por renglón (copiala de la barra del navegador, por ejemplo https://www.bidcom.com.ar/drones). También podés pegar una categoría principal, como https://www.bidcom.com.ar/bebes-y-ninos: si no muestra productos, se recorren solas sus subcategorías.

2Resultados

Después lo importás como siempre: WordPress → Productos → Importar → marcá "Actualizar productos existentes".

3Opcional: actualizar la tienda directo (sin importar el CSV)

Se configura una sola vez. En WordPress: WooCommerce → Ajustes → Avanzado → API REST → Añadir clave, permisos Lectura/Escritura. Copiá acá las dos claves que te muestra.

Cada tienda guarda su dirección y sus claves. Al abrir la extensión siempre empieza en DURTOM.

4Productos de Bidcom que no están en tu tienda

Aparece después de tocar "Ver qué cambiaría" en el paso 3. No se modifica nada: es solo una lista para que decidas cuáles cargar.
